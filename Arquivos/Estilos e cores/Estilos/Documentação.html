Configuração
O arquivo de configuração fica na raiz do projeto e é lido uma vez, na inicialização. Toda chave é opcional; o que não estiver escrito assume o padrão.
Formato
É um JSON simples, sem comentários. Chaves desconhecidas são ignoradas em silêncio.
{ "porta": 8080, "modo": "producao", "registro": { "nivel": "aviso" } }
A largura do texto é contida de propósito: linha longa demais cansa a leitura.
Precedência
Variável de ambiente vence o arquivo, e argumento de linha de comando vence as duas.
